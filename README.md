# WordBound

A word ladder puzzle game. Change one letter at a time to turn the start word into the target word, using only real words.

## Features
- Easy, medium and hard puzzles
- Shortest path found with Breadth-First Search (BFS)
- Hints, scoring, stats, achievements and a local leaderboard
- Light and dark theme
- Progress saved in the browser (localStorage)

## Tech
HTML, CSS and vanilla JavaScript. No frameworks.

## Run locally
Open index.html in a browser.
